# Go

The user has read what you last proposed (a plan, a set of options, a question you asked) and is telling you to proceed.

- **No arguments:** they agree with everything. Where you offered options, take your recommended one. Where you asked a question, take the default you suggested. Do not ask for confirmation again.
- **With arguments (or text before a trailing /go):** treat the text as amendments to your proposal. Apply them, keep everything else they did not contradict, and proceed. Ask only if the amendment truly conflicts with the proposal in a way you cannot resolve.

Either way, start working in this turn. Do not restate the plan back first.
